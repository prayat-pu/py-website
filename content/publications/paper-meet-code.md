This research project focuses on a deep learning approach to automatically link scholarly articles with their official software repositories on GitHub.

### Key Contributions
- **SPECTER Model:** Utilized for extracting information from both academic articles and software repositories.
- **Classification:** Applied machine learning models, with LightGBM achieving high performance in binary classification tasks.
